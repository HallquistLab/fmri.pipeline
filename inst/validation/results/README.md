# Frozen HRF-recovery comparison

See [the validation report](../../../HRF_ESTIMATION_VALIDATION.md) for methods,
interpretation and limitations. Files here are generated by
`inst/validation/report_hrf_recovery.R` from a completed 40-replicate run of
`inst/validation/hrf_recovery.R`.

- 12 scenarios, 40 independent datasets each: 480 datasets.
- Six methods at three fixed lambdas: 8,640 dataset/method/lambda summaries.
- 24 voxels, TR = 1 second, 220 observations per run; three runs except the
  two-run and run-drift scenarios. Paired intervals use datasets as replicates.
- Primary lambda = 0.01; sensitivity values = 0.001 and 0.1.
- Seeds: `8320000 + scenario_index * 10000 + replicate`; scenario order is fixed
  by `hrfv_scenarios()`.
- Estimation logic under test: commit `258373ddebf0ee4d0671315f97c916af6561ebe9`.
  This validation adds no estimation-logic changes.
- Simulation script MD5: `0875b8df423b413d4f4e415254e2213b`.
  This identifies the original script. The current script explicitly requests
  OLS/legacy mode after defaults changed, preserving its numerical experiment.
  New-workflow results are separate in `../noise_results`.
- R 4.5.1, OpenBLAS 0.3.30; `OPENBLAS_NUM_THREADS=1`, `OMP_NUM_THREADS=1`.
- Cached inverse evaluation agreed exactly with public application on the
  checked fitted dataset (maximum absolute difference zero).

`hrf_recovery_summary.csv` contains all-method means, Monte Carlo intervals and
finite replicate counts, in wide format. `hrf_recovery_paired.csv` contains paired
changes versus canonical, intervals, counts and improvement fractions. Gain
errors are measured relative to ideal gain one. A raw gain increase need not be
an improvement, so raw gains have no improvement-fraction entry. Undefined
metrics in the null scenario are NA, not zero. Shape errors use the known HRF;
neural errors use independently generated, acquisition-grid-projected truth.

Regenerating the experiment also writes `replicate_metrics.csv`,
`run_metrics.csv`, the full long tables, `settings.rds`, `environment.txt`, and
`public_application_check.txt`. Those raw artifacts are not committed. No
candidate, threshold, strength, or lambda was tuned against these results.
