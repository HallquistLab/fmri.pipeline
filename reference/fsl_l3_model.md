# Prepare a level 3 FSL FEAT group model from lower-level COPEs

Prepare a level 3 FSL FEAT group model from lower-level COPEs

## Usage

``` r
fsl_l3_model(l3_df = NULL, gpa)
```

## Arguments

- l3_df:

  a data.frame containing cope inputs for a given l3 model, as well as
  metadata that identify the model.

- gpa:

  a `glm_pipeline_arguments` object containing model specification
